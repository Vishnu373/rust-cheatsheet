# Functions
- Can be defined **anywhere** as long as it can be seen by the caller.
- **Parameters** => the variables that the function can accept, defined in function definition.
    - type annotation for each parameter is **required**.
- **Arguments** => values passed in place of parameters in function call.

---

## Statements
- instructions, which perform some action and **do not return** a value.
- Since, it doesn't return anything you can't assign a statement to another variable.
- Function definitions are statements.

---

## Expressions
- instructions, which perform some action and **returns** a value.
- it can be part of a statement.
    - Example:- `5 + 6` is an expression, it gives an output `11`.
- Function calls are an expression.
- Doesn't have a semicolon (`;`) in the end. Adding a semicolon makes it a statement.
