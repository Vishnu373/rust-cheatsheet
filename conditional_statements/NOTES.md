# Conditional statements
- `if`, `else if`, `else`
- `if` is **mandatory** while rest are **optional**.
- the condition **must be boolean** for the `if` block, else it will throw an error.
- Since, `if` block is an expression it can be assigned with a `let` variable.
    - However, the code contains `if` and `else` block then the return types should be **same** else throws an error.
    - Also, in such cases the `else` block is **mandatory**.
