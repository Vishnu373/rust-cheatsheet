# Loops
- `loop` -> the **infinite** loop by default unless we explicitly stop it manually.
    - Options to stop the flow:
        - `break` expression -> stop / break the execution at a specific point or condition.
        - `continue` -> skip a certain part of the flow upon reaching a specific point or condition.
- In case of nested loops, `break` or `continue` applies to **innermost** loop.
    - However, you can use a **loop label** to make it explicit on which loop the `break` or `continue` should apply on.
